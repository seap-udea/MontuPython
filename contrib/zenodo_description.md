# MontuPython Zenodo Description

This file contains the updated description for Zenodo.

## Option 1: Copy as Rich Text / Markdown
*(You can copy this text and paste it directly into Zenodo's rich text editor)*

**MontuPython** is a Python package intended to compute astronomical ephemerides in the ancient world, thousands of years before present. It was initially designed to compute ephemerides for ancient Egypt, but it can also be used to study astronomical phenomena in other sites of interest for cultural astronomy (archaeoastronomy).

The package was originally developed to streamline calculations on archaeoastronomy that were previously performed manually using astronomical software such as Stellarium. While there are already outstanding libraries for positional astronomy—such as [PyEphem](https://pypi.org/project/ephem/), [pyplanets](https://pypi.org/project/pyplanets/), and [PyMeeus](https://pypi.org/project/pymeeus/) (many of which make MontuPython possible)—our goal here is different. We aim to provide a tool that not only simplifies interaction with these libraries, but, more importantly, is specialized for the study of astronomical phenomena that occurred thousands of years ago.

While MontuPython places a special emphasis on ancient Egypt, the tool is broadly applicable to many other contexts. Its features are designed to support research across a diverse range of civilizations, making it a versatile resource for all archaeologists, historians, and cultural astronomers interested in humanity's relationship with the sky.

For detailed information on how to use the package, please refer to the [MontuPython Documentation on ReadTheDocs](https://montupython.readthedocs.io/).

Version 0.43.4 updates the package. See the full [release notes (WHATSNEW.md)](https://github.com/seap-udea/MontuPython/blob/main/WHATSNEW.md).
